Econometrics · Recap · Simulation 6

What a 95% confidence interval really means

100 research teams each draw their own sample of men and compute a confidence interval, β̂ ± critical value × SE. The true β (red dashed line) never moves. The intervals move, because each comes from a random sample. Our interval from Stata is shown at the top.

How to use this simulation
  1. Click Run 100 new studies. Green intervals contain the true β, red ones miss it. Count the misses: about 5 out of 100.
  2. Run it several times. The All runs box shows that, overall, about 95% of the intervals contain β.
  3. Switch the confidence level to 80% and then 99%. How do the width of the intervals and the number of misses change?
  4. Move N: the intervals get shorter, but the share of misses stays the same.
  5. Tick Also test H₀: β = 0. The intervals that exclude 0 are exactly the studies that would reject H₀.

Key idea: "95% confident" describes the method: 95% of intervals built this way contain the true β. Any single interval, including ours, either contains β or it does not, and we cannot know which.
