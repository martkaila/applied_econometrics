Regression and the conditional expectation function

Our aim is the conditional expectation function (CEF), E[Yi | Xi = x]: the average of Y at each value of X. Here Y is log weekly wage and X is years of education. The data come from a made-up population, so, unlike in real research, we know the true CEF and can check whether regression finds it.

How to use this simulation
  1. Draw the data. Each dot is a man. Click Draw new data a few times.
  2. The mean of Y. A regression with no explanatory variables, only a constant, gives exactly the average of Y.
  3. The CEF at one value of x. Move the slider. Compare the average computed by hand (only the men with x years) with the regression answer α̂ + β̂x.
  4. Is it the right number? Compare both with the true CEF. Then change the true relationship to Curved or Irregular, and try N = 20,000.
  5. A saturated model. Split the men into low and high education and regress Y on this 0/1 variable. Check that the regression recovers both group averages exactly, whatever the true relationship.

Key idea: OLS estimates the CEF. If the CEF is a straight line, a linear regression recovers it; if not, it gives the best linear approximation. A saturated regression, with one parameter for every value of X (for example, a regression on a single 0/1 variable), always recovers the CEF.
