Econometrics · Recap · Simulation 3b

One sample, one slope

The grey cloud is a made-up population of men: years of education and log weekly wage, with a true return to schooling of β = 0.046 (red dashed line). In real life we never see the cloud or the red line: we see one sample. Our Stata regression on 165 men gave β̂ = 0.046. What if we had drawn different men?

How to use this simulation
  1. Click Draw a new sample and run OLS. 165 men are picked at random (blue dots), and OLS fits a line through them (blue line). Its slope β̂ appears on the right.
  2. Click again several times. Same population, same regression, different men. Compare each new β̂ with the earlier ones, listed under the big number.
  3. Change N to 30 and draw a few samples. Then try 1,000. How much do the lines move now?
  4. Untick Keep the lines from earlier samples to see only the latest sample.

Key idea: β̂ depends on which men happen to be in the sample, so it is a random variable. The smaller the sample, the more it varies.
